# Protocol package

This directory contains the reproducibility and pre-audit layer for the NileRed BZ reaction twin.

- [`REPRODUCIBILITY_PROTOCOL.md`](REPRODUCIBILITY_PROTOCOL.md) — gated, step-by-step computational protocol and release criteria.
- [`PRE_AUDIT_REPORT.md`](PRE_AUDIT_REPORT.md) — findings, evidence register, blockers, and corrective actions.
- [`validation_manifest.json`](validation_manifest.json) — machine-readable status and artifact inventory.

The package is deliberately non-operational for wet-lab work. It does not contain reagent identities, quantities, preparation, heating, mixing, quenching, or waste instructions. “Validated” in this package means validated software execution and documented review gates—not validated chemistry or laboratory safety.
