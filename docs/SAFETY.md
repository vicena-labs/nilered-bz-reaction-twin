# Safety and scientific boundary

This repository is a mathematical and computational companion. It intentionally
omits reagent identities, concentrations, preparation order, heating, mixing,
quenching, and waste handling. Rowan is used only as a potential route for
selected molecular calculations after structures and budget are explicitly
approved.

A model run is not a laboratory validation. A Rowan result is not a complete
reaction mechanism unless the structure, method, solvent, charge, spin, and
connectivity checks support that interpretation.
